# 🔌 Backend Services Reference (FastAPI & Pydantic)

This directory documents core backend engineering concepts. It organizes work related to schema validations, types coercion, dynamic configuration models, and clean API endpoints.

---

## 📂 Sub-Directory Structure

*   📁 **[`pydantic/`](./pydantic/)**
    *   Contains files migrated from `pydantic_learn/` focusing on data serialization, strict validation schemas, type coercion, and nested schema bindings.
*   📁 **[`fastapi/`](./fastapi/)**
    *   Contains files migrated from `Api_work/` detailing server configurations, path operations, query parameters, dependency injections, and model parsing integrations.

---

## 🎯 Key Learning Focus
*   **Declarative Schemas:** Setting strict input models using standard type hinting.
*   **API Design:** Implementing clean HTTP method pathways aligned with RESTful paradigms.
*   **Automatic Docs:** Generating OpenAPI interfaces dynamically from Pydantic structures.

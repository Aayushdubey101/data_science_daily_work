# 📊 Data Visualization Reference

This directory serves as a comprehensive visual styling guide, detailing core visual plotting paradigms across static and interactive frameworks.

---

## 📂 Sub-Directory Structure

*   📁 **[`matplotlib/`](./matplotlib/)**
    *   Contains files migrated from `matplotlip/` documenting subplots configuration, layout aesthetics, customized axes, labels, and figure formats.
*   📁 **[`plotly/`](./plotly/)**
    *   Contains files migrated from `ploty/` demonstrating dynamic interactive charts, tooltips, slider controllers, and browser-ready plots.

---

## 🎯 Core Concepts
*   **Static Layouts:** Fine-tuning subplots, styling guidelines, and multi-axes plotting.
*   **Interactive Visuals:** Structuring hover labels, responsive charts, and reactive data stories.
